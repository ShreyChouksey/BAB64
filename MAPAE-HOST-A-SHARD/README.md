## Status and limitation

This mirror is controlled by the same MAPAE operator. It verifies the mechanics—assignment, exact-byte publication, public retrieval, hashing and registry entry—but **does not count as an independent volunteer host**.

The next milestone is the first verified placement on a domain or public repository administered by an independent consenting participant.

## Security boundary

This directory contains public Bitcoin addresses only. It contains no private keys, WIFs, seeds, mnemonics, entropy source, recovery secrets, xprvs or signing credentials. Publication is not a request to send funds.

**Maximum exposure. Maximum longevity. Maximum independent scrutiny. Zero private-key disclosure. Zero unauthorized activity. Zero spam. Zero deception. Zero circumvention.**
